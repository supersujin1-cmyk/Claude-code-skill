# Plan: 모바일 웹 가계부 (v3)

**Complexity**: Medium
**Status**: 1단계 + 핵심 계산 + 대시보드 뼈대 완료, 엑셀 변환기와 KB증권 API는 자료 대기

## Summary
KB국민카드·삼성카드·국민은행 내역은 엑셀 업로드로, KB증권(국내+해외)은 Open API로 가져와
매일 확인하는 주간 대시보드로 보여 준다.
Streamlit + Supabase(로그인, 행 단위 보안) + Streamlit Community Cloud.

| 업로드 | 엑셀 올리기 (변환기 완성 후) |

## Patterns to Mirror
기존 코드 없음 → 이 저장소에서 새로 정함.
- 금액: `decimal.Decimal`, 원 단위. 출금 음수, 입금 양수.
- 핵심 로직(`ledger/`)은 표준 라이브러리만 사용 → 화면/DB 없이 테스트 가능.
- 외부 연동(파일, 증권 API, DB)은 `Protocol` 인터페이스 뒤에 둠 → 교체 가능.
- 연말정산 공제율·한도는 `YearEndRules`로 분리 → 해마다 값만 교체.
- 테스트: `tests/`, pytest, 가짜 데이터만 사용.
